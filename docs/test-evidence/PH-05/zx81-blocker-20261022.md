## Blocker (gameplay)

81-libretro **does not** call `eo_loadp` on content load. `.p` files are wrapped as TZX tape blocks; Flash Load still requires the user to type **`LOAD ""`** at the BASIC `K` cursor.

Measured in Chromium (EmulatorJS 4.2.3):

1. Core boots to white screen + `K` cursor (`lit≈545595`).
2. `LOAD ""` via remapped RetroPad face buttons does **not** reliably produce on-screen `LOAD` / flash-load the fixture (framebuffer hash stays at the idle `K` cursor).
3. Keyboard overlay (Select) was observed once, then became non-reproducible under the pinned joypad option set — overlay steals joymap when visible.
4. Upstream `eo_loadp` (direct memory inject + PC=`0x0207`) is present in 81-libretro source but **commented out** in `retro_reset`; rebuilding a patched WASM core is the credible unblock path.

**Not VERIFIED_PLAYABLE.** Do not mark checkbox until input-driven Dot motion + catalog offline pass.
