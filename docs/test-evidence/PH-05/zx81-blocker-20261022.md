## Blocker (gameplay) — still open

Measured in Chromium with both stock `81` and patched `81_eo`:

1. Core boots to white screen + BASIC `K` cursor (`lit≈545595`).
2. `eo_loadp` path in `81_eo` does **not** produce a running Dot screen (still idle `K` after boot + moves).
3. `LOAD ""` via remapped RetroPad face buttons and via Direct Keyboard Input also leave the framebuffer on the idle `K` hash.
4. Upstream keybovl only polls ports whose device mask is JOYPAD/KEYBOARD; `81_eo` forces JOYPAD each frame — still insufficient for verified LOAD/play.

**Not VERIFIED_PLAYABLE.** Keep EXPERIMENTAL.
