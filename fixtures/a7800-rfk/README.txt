What's this
-----------

rfk7800 is an implementation of robotfindskitten
for the Atari 7800. It runs on NTSC and PAL consoles.
rfk7800 is available in source and binary form from
http://rfk7800.sourceforge.net/.


Instructions
------------

rfk7800 is controlled with the left joystick.
In the main menu, select one of the menu entries
(joystick up/down), then press one of the fire buttons.
For information on how to play, read the in-game
instructions which are available through the main menu.

The rfk7800 ROM is a vanilla 32k ROM.
