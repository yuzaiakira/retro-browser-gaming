# Local development HTTPS certificates

Generated by `scripts/generate-dev-https-certs.sh` (OpenSSL local CA).

- **Not** system-trusted by default.
- HTTPS smoke tests import `ca.cert.pem` into a temporary Chromium NSS database.
- Private keys must never be committed (see `.gitignore`).

This supports **LOCAL_HTTPS_VERIFIED** evidence only. It is not production staging.
