# RBG FDS Move Demo

First-party minimal Famicom Disk System fixture for PH-12 interactive A/B/A proof.

## License

MIT — Retro Browser Gaming project. No Nintendo game code or assets.

## Behavior

- Boots under OpenDiskSysROM / FCEUmm (size-only BIOS check).
- Shows a single 8×8 sprite.
- **Left** / **Right**: move sprite on X (±2 px per frame while held).
- **A**: toggle sprite Y by 16 px.

## Provenance

Generated by `scripts/build-fds-rbg-move-demo.py` (6502 machine code + FDS disk packer).
SHA-256 of `.fds` is recorded in `docs/emulator-builds/fds-open-bios-feasibility.md`.
